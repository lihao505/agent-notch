# Agent Notch 产品能力规格

目标是构建独立、可维护的原生 macOS 多 Agent 刘海工作台。本文只描述用户需求和本项目验收标准，不以任何竞品的界面、素材、文案或实现为规格来源。

## 产品能力基线
- 通用：登录启动、悬停展开（默认 0.15s）、智能抑制、全屏隐藏、自动收起、提醒停留、空闲清理、点击跳转
- 集成：按 CLI 管理 Hook、自动配置新 CLI、IDE 扩展、精确跳转规则
- 通知：完成提醒、子 Agent 时机、专注/锁屏/录屏静默、目录/首条提示词/启动器过滤
- 显示：紧凑/详细布局、显示器选择、字号和面板尺寸、项目/工作树/模型/子 Agent/活动详情
- 用量：顶部显示、已用/剩余切换、自动/Claude/Z.ai/Codex/Kimi 服务商
- 高级：快捷键、SSH 远程、实验室
