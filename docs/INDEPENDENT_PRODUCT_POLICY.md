# Agent Notch 独立产品政策

本文件是产品与工程的强制发布规则，不构成法律意见。

## 设计与实现边界

- 从用户工作流描述、可公开验证的协议、平台官方文档和自主设计中定义需求。
- 不复制其他产品的源代码、反编译结果、资源文件、图标、动效帧、截图、营销文案、付费/激活逻辑或可识别的整体界面表达。
- 不以“复刻”“平替”或任何第三方产品名作为公开宣传语。
- 不暗示与 Apple、Anthropic、OpenAI、Vibe Notch 或其他 Agent 厂商存在官方关系、认可或合作。
- 使用 Claude、Codex 等名称时，只作兼容性说明，并附“商标归其各自权利人所有”的声明。

## 开发证据链

每个面向用户的设计变更都应保留以下任一来源：

1. 用户需求、产品需求文档或原创设计稿；
2. 平台官方 API/协议文档；
3. 有明确许可证的第三方组件或素材；
4. 本项目自行创建的源码、Pixelorama 源文件或设计资产。

评审记录应说明“解决什么用户问题”，而不是“模仿哪个产品”。

## 发布闸门

- 在公开 GitHub 仓库前完成 `docs/ASSET_PROVENANCE.md` 中每一项的权属确认。
- 保留 Apache-2.0 `LICENSE.md` 与 `NOTICE`；为实质改动的上游文件加入显著修改通知。
- 使用自主拥有的产品名、Bundle ID、App 图标、Sparkle key、更新域名和发布账号。
- 默认单次审批。自动/完全信任只能作用于普通工具请求，不能跳过问答、计划确认、系统权限或外部账户授权。
- 在发布前进行商标检索、依赖许可证审计、隐私政策审阅和人工视觉相似性审查。

## 失败处理

如果任何图标、像素帧、声音、文案、截图或设计来源无法确认：不发布该资产；以自制替代物取代后再进入构建。
