# Dense Vibe Pet frames

These files are reproducible rendering derivatives of the original AI-generated
frames in `Resources/VibePet`.

- Generated by `scripts/generate-dense-vibe-pet.swift`
- 10× coordinate precision
- 19/20 cell coverage, leaving a 1/10-scale transparent gap
- Hard rectangular edges and transparent background
- No baked blur, bloom, or glow
- Glow remains a SwiftUI rendering effect

Regenerate from the repository root:

```sh
swift scripts/generate-dense-vibe-pet.swift .
```
